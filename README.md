# RagBond

RagBond's distributed ledger engine enables high-performance, real-time-processing of complex transactions across scalable, auto-configured nodes.

RagBond is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/RagBond.git`
2. `cd RagBond`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
